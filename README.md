# HIVE — запуск за ~20 хвилин

Що вже вміє сайт:
- реєстрація з поштою і паролем, лист-підтвердження, вхід і вихід;
- анкета: ім'я, район Києва, місцевість, будинок/ЖК, «про себе»;
- особиста сторінка з фото профілю: дописи з фото (до 4), вкладка «Фото», підписники, рейтинг, посилання-запрошення;
- стрічка «Рекомендації» / «Підписки» / «Мій район», вподобання, поширення (репости), лічильник переглядів;
- рейтинг користувачів: підписник +10, запрошений друг +20, вподобання +1, поширення +3;
- список сусідів з пошуком;
- **адмінка `/admin`**: усі зареєстровані користувачі (пошта, ім'я, район, будинок, дата реєстрації, підтвердження пошти, останній вхід, кількість дописів, статус), статистика, фільтри, пошук, експорт у CSV, картка користувача з усіма даними, блокування публікацій, видалення дописів і акаунтів, повторне надсилання листа підтвердження.

Знадобляться три безкоштовні акаунти: **GitHub**, **Supabase** (база даних і пошта) і **Vercel** (хостинг).

---

## Крок 1. Supabase: база даних

1. Зайди на https://supabase.com, натисни **Start your project** і зареєструйся. **Використай ту саму пошту, на яку створюватимеш тестовий акаунт HIVE**: стандартна пошта Supabase надсилає листи лише учасникам команди проєкту (див. крок 6).
2. **New project**: назва `hive`, придумай і збережи пароль бази, регіон **Central EU (Frankfurt)**, тобто найближчий до України. Зачекай 1–2 хвилини.
3. Ліве меню → **SQL Editor** → **New query**. Відкрий файл `supabase/schema.sql`, скопіюй увесь текст, встав і натисни **Run**. Має з'явитися «Success». Потім так само виконай по черзі `supabase/migration-02.sql`, `-03`, `-04` і `-05`.
4. Ліве меню → **Project Settings** → **API Keys** (або **API**). Скопіюй собі в нотатки:
   - **Project URL** (вигляд `https://abcd.supabase.co`, є також у Settings → Data API);
   - **anon / publishable** ключ (публічний);
   - **service_role / secret** ключ (секретний! нікому не показуй і не публікуй).

## Крок 2. GitHub: код

1. Зареєструйся на https://github.com.
2. Вгорі **+** → **New repository** → назва `hive`, **Private** → **Create repository**.
3. На сторінці репозиторію натисни посилання **uploading an existing file**, розпакуй архів і перетягни **усі файли й папки з папки `hive-app`** (саму папку перетягувати не треба, лише вміст). Натисни **Commit changes**.

## Крок 3. Vercel: запуск сайту

1. Зайди на https://vercel.com і натисни **Sign Up** → **Continue with GitHub**.
2. **Add New… → Project** → навпроти `hive` натисни **Import**.
3. Розгорни **Environment Variables** і додай по одній:

| Name | Value |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Project URL з кроку 1 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon / publishable ключ |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role / secret ключ |
| `ADMIN_EMAILS` | твоя пошта (кілька адмінів — через кому) |
| `NEXT_PUBLIC_SITE_URL` | поки `https://example.com`, замінимо в кроці 4 |

4. Натисни **Deploy** і зачекай 1–2 хвилини. Отримаєш адресу на кшталт `https://hive-abc123.vercel.app`. **Це і є твій сайт.**

## Крок 4. Прописати адресу сайту

1. Vercel → твій проєкт → **Settings → Environment Variables** → `NEXT_PUBLIC_SITE_URL` → **Edit** → встав свою адресу (без `/` в кінці) → Save. Потім **Deployments** → у останнього пункту меню **⋯** → **Redeploy**.
2. Supabase → **Authentication → URL Configuration**:
   - **Site URL**: твоя адреса з Vercel;
   - **Redirect URLs** → **Add URL**: `https://твоя-адреса.vercel.app/**`.

## Крок 5. Лист підтвердження українською

Supabase → **Authentication → Emails** (або Email Templates) → **Confirm signup**:
- **Subject**: `Підтвердь реєстрацію в HIVE`
- **Body** (замінити все):

```html
<h2>Ласкаво просимо у HIVE!</h2>
<p>Щоб завершити реєстрацію, натисни на посилання:</p>
<p><a href="{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=email&next=/onboarding">Підтвердити пошту</a></p>
<p>Якщо ти не реєструвався в HIVE, просто проігноруй цей лист.</p>
```

Натисни **Save**. Таке посилання спрацює, навіть якщо лист відкрити на іншому пристрої.

## Крок 6. Перший тестовий акаунт

1. Відкрий свій сайт → **Зареєструватися** → введи ім'я, пошту з `ADMIN_EMAILS` і пароль.
2. Відкрий лист від Supabase (перевір «Спам») → **Підтвердити пошту** → заповни анкету.
3. У верхньому меню з'явиться **Адмінка**. Там видно себе як першого користувача.

## Перед тим як кликати реальних людей

- **Пошта для всіх.** Стандартна пошта Supabase надсилає лише кілька листів на годину і тільки на адреси учасників твоєї команди в Supabase. Для справжніх користувачів підключи власний поштовий сервіс, наприклад **Resend** (https://resend.com, безкоштовно до 3000 листів на місяць): Supabase → **Authentication → SMTP Settings** → увімкни **Custom SMTP** і встав дані з Resend. Для цього знадобиться свій домен.
- **Свій домен** (наприклад, `hive.com.ua`): Vercel → Settings → **Domains** → Add. Після цього онови `NEXT_PUBLIC_SITE_URL` і Site URL у Supabase.
- **Політика конфіденційності.** Ти зберігаєш персональні дані (пошта, район, будинок) і приватні повідомлення, тож потрібна сторінка з умовами і політикою конфіденційності. Обовʼязково внеси туди рядок про модерацію листувань, наприклад: «Повідомлення приватні, але можуть бути переглянуті модерацією за скаргою або з міркувань безпеки.» Саме це робить доступ адміна до чатів законним. У самому застосунку такий напис уже показано кожному в чаті. Краще проконсультуватися з юристом.

## Як вносити зміни

Зміни файл у репозиторії на GitHub (олівець ✏️ → Commit), і Vercel сам перезбере сайт за хвилину.

Локальний запуск для розробки: `npm install`, скопіювати `.env.example` у `.env.local` і заповнити, потім `npm run dev` → http://localhost:3000.
